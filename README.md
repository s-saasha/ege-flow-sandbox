# EGE-Flow

Веб-сервис для интерактивной подготовки к ЕГЭ по математике и информатике.
Учебный проект команды «Арбуз» по дисциплине «Разработка IT-проектов».

Главный документ проекта — техническое задание: [docs/TZ_EGE-Flow_v2.docx](docs/TZ_EGE-Flow_v2.docx)
(текстовая копия: [docs/TZ.md](docs/TZ.md)). При расхождении README и ТЗ верно ТЗ.

## Возможности

Единственная роль — «Участник». Доступно:

- тренировка по темам;
- варианты ЕГЭ, собираемые из банка заданий;
- автоматическая проверка ответов и первичные баллы;
- карточки с интервальным повторением;
- игра EGE-Rush (механика Flappy Bird, на препятствиях — варианты ответов);
- персональная статистика.

В задания входят только вопросы с кратким ответом. Админ-панели нет: контент загружается через миграции и seed-скрипты.

| Frontend | React 19 |

Используются только открытые библиотеки с лицензиями MIT, Apache 2.0 или BSD.

## Аутентификация

Вход и регистрацию выполняет внешний сервис аутентификации (проект летней практики).
Backend только проверяет подпись и срок действия выданного им JWT и не хранит пароли.
Пока доступа к сервису нет, используется заглушка (stub).

## Работа с репозиторием

- В `main` напрямую не коммитим и не пушим.
- Работаем в ветках `feature/…`, `fix/…`, `docs/…` и вливаем через pull request с ревью хотя бы одного участника команды.
- Коммиты небольшие, в формате `feat: …`, `fix: …`, `docs: …`.
- Секреты (пароли, ключи, `.env`) не коммитим. Переменные окружения описываем в `.env.example`.
- Репозиторий публичный: личных данных в нём быть не должно.
