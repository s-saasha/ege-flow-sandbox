# Продуктовые гайдлайны по заданиям

Как выглядит и ведёт себя каждый тип задания. Документ для ролей 2 и 3 (макеты)
и для проверки в прототипе. Основа: ТЗ, FR-030 — FR-034, FR-039, приложение В.

## Общее для всех типов

- Сверху номер задания в попытке и условие. Формулы показываются из LaTeX.
- Ответ можно менять до тех пор, пока он не отправлен (FR-031).
- Статус ответа виден на панели номеров: черновик, сохранён, отправлен.
- До завершения попытки показывается только статус ответа. «Верно» и «неверно»
  не показывается (FR-033). Это нужно проверить в каждом макете попытки.
- Отправленный ответ изменить нельзя. Поле заблокировано, рядом короткая
  подсказка, например: «Ответ отправлен, изменить его нельзя».
- Кнопки: «Сохранить», «Отправить ответ», «Завершить».

## Числовой ответ (NUMERIC)

- Одно поле ввода.
- Принимает запятую и точку: `0,5` и `0.5` — один и тот же ответ.
- Пробелы по краям игнорируются.
- Разрешены цифры, минус и один разделитель. Буква в поле — ошибка ввода
  с понятным текстом, например: «Введите число, например 12 или -3,5».
- Пустое поле можно оставить: неотвеченное задание дает 0 баллов (FR-034).

## Выбор одного варианта (SINGLE_CHOICE)

- Список вариантов, выбрать можно один (радиокнопки).
- Повторный клик по выбранному варианту не снимает выбор. Это нужно решить
  в макете и показать в прототипе одинаково везде.
- Варианты подписаны буквами `a`, `b`, `c`, `d` внутри системы. Пользователь видит
  только текст вариантов (при желании можно показывать «А», «Б», «В», «Г»).

## Выбор нескольких вариантов (MULTIPLE_CHOICE)

- Список с флажками, можно выбрать любое число вариантов.
- В условии должно быть сказано «выберите все…», чтобы было понятно, что вариантов несколько.
- Проверка по полному совпадению набора: порядок не важен, частичных баллов нет.

## Что видно на экране результата (FR-039)

Для каждого задания: ответ пользователя, «верно / неверно» и эталонный ответ.
Для выбора эталон показывается текстом вариантов, а не их `id`.

## Баллы

- Баллы за задание задаются в `points`. В примерах стоят 1 и 2.
- Первичные баллы — сумма `points` верных заданий. Процент выполнения —
  первичные баллы, делённые на максимум (FR-034).

## Структура варианта

В примерах она учебная: 4 номера по математике и 3 по информатике.
Это не официальная структура КИМ ЕГЭ: в ТЗ её нет, её нужно внести перед запуском.
