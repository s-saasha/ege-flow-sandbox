# Формат оцифровки заданий (роль 5)

Задания хранятся в JSON-файлах, по одному файлу на предмет. Из них seed-скрипт
заполняет таблицы `Subject`, `Topic` и `Question` (ТЗ, п. 4.3.2).
Схема файла: [question.schema.json](question.schema.json).
Примеры: [examples/](examples/). Проверка примеров: `python3 check_examples.py`.

Все задания в примерах придуманы нами для демонстрации. Это не задания ФИПИ.

## Структура файла

```json
{
  "subject": "Математика",
  "variant_structure": [ {"exam_number": 1, "count": 1} ],
  "questions": [ { ...задание... } ]
}
```

- `subject` — название предмета (`Subject.name`).
- `variant_structure` — структура варианта ЕГЭ (`Subject.variant_structure`, FR-036).
  Это список пар: номер задания и сколько таких заданий взять.
  Названия полей `exam_number` и `count` взяты из ТЗ, других в ТЗ нет.
- `questions` — список заданий.

## Поля задания

| Поле | Что это | Колонка `Question` |
|---|---|---|
| `topic` | название темы; тема создаётся, если её ещё нет | `topic_id` |
| `exam_number` | номер в варианте ЕГЭ или `null` | `exam_number` |
| `text` | условие | `text` |
| `question_type` | `NUMERIC`, `SINGLE_CHOICE` или `MULTIPLE_CHOICE` | `question_type` |
| `options` | варианты ответа, для `NUMERIC` — `null` | `options` |
| `correct_answer` | эталонный ответ | `correct_answer` |
| `points` | баллы за верный ответ (по умолчанию в ТЗ — 1) | `points` |

## Типы ответа и правила проверки (FR-033)

| Тип | `options` | `correct_answer` | Как проверяется |
|---|---|---|---|
| `NUMERIC` | `null` | число, например `-3` или `0.5` | ответ и эталон сравниваются как числа; запятая и точка равны, пробелы по краям убираются |
| `SINGLE_CHOICE` | список `{"id", "text"}` | `id` одного варианта, например `"c"` | совпал выбранный вариант |
| `MULTIPLE_CHOICE` | список `{"id", "text"}` | список `id`, например `["a", "c"]` | набор совпал полностью, порядок не важен |

Баллы: за верный ответ ставится `points`, за неверный или пустой — 0, частичных баллов нет.
Сумма `points` всех заданий варианта — это `max_score` попытки (FR-034).

## Правила записи

- Формулы пишем в LaTeX между знаками доллара: `$x^2 - 5x + 6 = 0$`.
  В JSON обратная косая черта удваивается: `"$\\frac{1}{2}$"`.
- Код пишем в обратных кавычках: `` `print(5)` ``.
- `id` вариантов — короткие латинские буквы `a`, `b`, `c`, `d`.
- В заданиях только краткий ответ (ТЗ, п. 2.3.2).
- Для `exam_number` в варианте нужно хотя бы одно задание с этим номером, иначе
  сборка варианта вернёт 409 (FR-036).
- Для режима EGE-Rush нужны задания типа `SINGLE_CHOICE` (FR-051).
