# Код ошибки → что видит пользователь (роль 4)

Для ролей 2 и 3: по этой таблице делаются состояния ошибки в макетах.
Формат ответа об ошибке по ТЗ (п. 4.1.2): `{"detail": "описание"}`.
Поле `detail` написано для разработчика, пользователю его не показываем:
текст для пользователя берётся из таблицы. Тексты ниже — предложение, их можно править.

## Таблица

| Код | Когда бывает | Что видит пользователь | Что можно сделать |
|---|---|---|---|
| 400 | некорректный запрос, который не должен уходить с нашего клиента | «Что-то пошло не так. Обновите страницу и попробуйте ещё раз» | кнопка «Обновить» |
| 401 | токена нет, он просрочен или подделан (FR-001, FR-005) | «Сессия закончилась. Войдите снова» | переход на экран входа; ответы, которые не успели сохраниться, показать пользователю |
| 403 | попытка открыть чужие данные (FR-010); до согласия на обработку ПДн (предложение, см. сверку) | «У вас нет доступа к этим данным» / «Чтобы продолжить, дайте согласие на обработку данных» | вернуться на главную / окно согласия |
| 404 | предмета, темы, попытки, карточки или игровой сессии нет (FR-021, FR-010) | «Страница не найдена. Возможно, она была удалена» | кнопка «На главную» |
| 409 | см. разбор ниже | зависит от причины | зависит от причины |
| 422 | данные не прошли проверку: пустой или неверный формат ответа, неверный параметр `count` | «Проверьте введённые данные» и подсказка у поля | исправить поле; кнопка остаётся доступной |
| 500 | ошибка на сервере | «Сервис временно недоступен. Попробуйте через несколько минут» | кнопка «Повторить» |
| нет ответа | нет сети, таймаут, обрыв WebSocket | «Нет связи с сервером. Проверьте интернет» | «Повторить»; в попытке введённый ответ остаётся на экране |

## Разбор 409 (конфликт состояния)

| Где | Причина (откуда в ТЗ) | Что видит пользователь |
|---|---|---|
| Тренировка по теме | в теме нет заданий (FR-035) | «В теме пока нет заданий» и кнопка «Выбрать другую тему» |
| EGE-Rush | в теме нет подходящих заданий (FR-050) | «В теме нет вопросов для игры» и кнопка «Выбрать другую тему» |
| Вариант ЕГЭ | у предмета нет структуры варианта или для какого-то номера нет заданий (FR-036) | «Вариант ЕГЭ по этому предмету пока недоступен» |
| Отправка ответа | ответ уже отправлен (статус FINAL, FR-033) | «Ответ уже отправлен, изменить его нельзя» |
| Сохранение ответа после завершения | попытка завершена (FR-034; код 409 — предложение, в ТЗ не указан) | «Попытка завершена, ответы изменить нельзя» |
| Повторное завершение | попытка уже завершена (предложение, в ТЗ не указано) | показать результат попытки |

## Правила для макетов

- На каждом экране, который ходит в API, нужны четыре состояния: загрузка, пусто, ошибка, успех.
- Ошибка всегда с текстом и с действием (кнопка или ссылка). Тупиков быть не должно.
- Введённые пользователем данные при ошибке не пропадают.
- Блокировка поля всегда с объяснением причины (иначе штраф за «непонятную блокировку»).
- 401 — единственная ошибка, которая выбрасывает пользователя на экран входа.
