Что взято из ТЗ, а что предложено нами:

- Пути, методы и коды ошибок взяты из ТЗ.
- Поля запросов и ответов в ТЗ не описаны, их названия выбраны по сущностям п. 4.3.2.
- Всё, чего нет в ТЗ, помечено «ПРЕДЛОЖЕНИЕ» или `x-proposal: true`: методы `GET /users/me` и
  `POST /users/me/consent` (согласие на ПДн), поля `has_exam_variant`, `due_count`, `is_due`,
  вопросы в ответе `POST /game/sessions`, формат сообщений WebSocket, код 409 после завершения попытки.
- Такие места нужно утвердить и внести в ТЗ дополнением по п. 1.8 либо убрать из спецификации.

Просмотр спецификации: открыть `openapi.yaml` в [Swagger Editor](https://editor.swagger.io/)
(скопировать содержимое файла).
